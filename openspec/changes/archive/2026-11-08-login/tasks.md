# Tasks

Порядок работы в каждой задаче с кодом приложения: сначала тест, запустить его и увидеть, что он красный; потом код; снова тест — зелёный. Название теста — название сценария из спеки. Для тестов нужна запущенная база и Mailpit: `docker compose up -d`. Решения, на которые ссылаются задачи, — в `design.md`.

Работа идёт в ветке `login`. Скрипты выкатки и CI автотестами не покрываются (CLAUDE.md) — их проверяет настоящая выкатка.
