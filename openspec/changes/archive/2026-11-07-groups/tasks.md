# Tasks

Порядок работы в каждой задаче с кодом приложения: сначала тест, запустить `pnpm test` и увидеть, что он красный; потом код; снова `pnpm test` — зелёный. Название теста — название сценария из спеки. Для тестов нужна запущенная база: `docker compose up -d`.

e2e (Playwright) и CI по решению владельца — позже, отдельной задачей. Сценарии, где проверяются только нажатия в браузере, автотеста логики не получают — их тест появится вместе с e2e, а сейчас они проверяются вручную в 10.2 и 11.8: «Вход с главной и обратно», «Передумать» (переименование), «Передумать удалять», «Отмена» в форме, «Групп нет» на главной, а из доработки — «Enter на группе, которая уже есть», «Enter в пустом поле», «Esc не убирает группы», «Enter в поле «Группы» не сохраняет форму», «Enter в пустом поле формы». У «Выбрать группу с клавиатуры» и «Создать группу с клавиатуры» тест логики проверяет, какой пункт выберет Enter, а само нажатие — вручную.
